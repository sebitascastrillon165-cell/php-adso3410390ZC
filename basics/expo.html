ord()

Propósito: Convierte el primer byte de un string a un entero (0-255). Útil para obtener el código ASCII.

Sintaxis

ord($string): int

Ejemplo

$letra = "A";
echo ord($letra);
Resultado: 65
Consejo: No usar con tildes o emojis (multibyte). Usar mb_ord().

shuffle()

Propósito: Mezcla los elementos de un array aleatoriamente.

Sintaxis

shuffle(array &$array): bool

Ejemplo

$cartas = ["As", "Rey", "Reina"];
shuffle($cartas);
print_r($cartas);
Resultado: Array ( [0] => Reina [1] => As [2] => Rey ) (varía cada vez)
Consejo: Destruye las claves asociativas originales.

sprintf()

Propósito: Devuelve una cadena formateada. Útil para dar formato a números o construir cadenas complejas.

Sintaxis

sprintf(string $format, ...$values): string

Ejemplo

$precio = 1250.5;
echo sprintf("Total: $%.2f", $precio);
Resultado: Total: $1250.50
Consejo: Asegurar que el número de argumentos coincida con los marcadores (%).

addslashes()

Propósito: Escapa comillas y barras invertidas añadiendo una barra invertida.

Sintaxis

addslashes(string $string): string

Ejemplo

$nombre = "O'Reilly";
echo addslashes($nombre);
Resultado: O\'Reilly
Consejo: NO usar para bases de datos (Inyección SQL). Usar PDO.

array_diff()

Propósito: Devuelve los valores del primer array que no están en los demás.

Sintaxis

array_diff(array $array, ...$arrays): array

Ejemplo

$inv = ["manzana", "pera"];
$vendidos = ["pera"];
print_r(array_diff($inv, $vendidos));
Resultado: Array ( [0] => manzana )
Consejo: Compara como strings (el 1 y "1" son iguales).

array_unique()

Propósito: Elimina valores duplicados, conservando la primera aparición y las claves originales.

Sintaxis

array_unique(array $array): array

Ejemplo

$correos = ["a@t.com", "b@t.com", "a@t.com"];
print_r(array_unique($correos));
Resultado: Array ( [0] => a@t.com [1] => b@t.com )
Consejo: Conserva índices. Usa array_values() para reindexar.

chmod()

Propósito: Cambia los permisos de un archivo o directorio (Linux/Unix).

Sintaxis

chmod(string $filename, int $mode): bool

Ejemplo

if (chmod("archivo.txt", 0644)) {
    echo "Permisos cambiados";
}
Resultado: Permisos cambiados
Consejo: Siempre anteponer un 0 (octal) al número de permisos.

file_get_contents()

Propósito: Lee todo el contenido de un archivo y lo devuelve como string.

Sintaxis

file_get_contents(string $filename): string|false

Ejemplo

$txt = file_get_contents("texto.txt");
if ($txt !== false) { echo $txt; }
Resultado: (Muestra el contenido del archivo)
Consejo: Verificar siempre el retorno con === false por si el archivo no existe.

http_response_code()

Propósito: Obtiene o establece el código de estado HTTP (200, 404, 500, etc.).

Sintaxis

http_response_code(int $code = 0): int|bool

Ejemplo

http_response_code(404);
echo "Código: " . http_response_code();
Resultado: Código: 404
Consejo: Llamar antes de cualquier salida HTML (echo) para evitar errores de cabeceras.
